## 1. Concept
The Jukebox Room is a dark, full-screen theater room with an MP3 player. Interactive CDs (from `disc-cascade-carousel.tsx`) float and slide in and out. The UI is very slim and fades away over time so the music and visuals take over. It is separate from the Soundtrack panel, which stays untouched. Room name is a PLACEHOLDER: "Jukebox Room".

## 2. Unlock and location

## 3. Theater levels (core system)
"Dampen" is a muffling amount: higher means more muffled, 0 is full clear sound.

| Level | Name | UI | Dampen | Duration |
|---|---|---|---|---|
| 1 | Active | full opacity | 3.5 | first 4 s after any touch |
| 2 | Dim | translucent | 1.5 | next 20 s |
| 3 | Theater | hidden | 0 | until the screen is touched again |

After a touch: 0 to 4 s Level 1, 4 to 24 s Level 2, then Level 3. All changes ramp smoothly. Any touch returns to Level 1 and restarts the timer. While paused, stay at Level 1.
- At Level 3 the first touch only wakes the UI. It must not also pause, skip or select a disc.
- Optional "Theater Mix" toggle: off keeps audio at dampen 0 at every level (only the UI fades); on applies the table.
- Open question: should a touch return to Level 1 or Level 2? Default Level 1.

## 4. Audio (REVISED after recon)
Recon facts (`src/game/audio/musicPlayer.tsx`, `.agents/memory/studio-engine.md`):
- There is exactly ONE `AudioContext` for the whole app, from `useMusicPlayer().ensureAudioContext()`. The Jukebox must never create its own.
- The player already owns the graph: `<audio>` -> `MediaElementSource` -> `Analyser` -> `destination` (`connectAnalyser`, around line 626). `analysis.ts` reads that analyser for beat detection.

Design:
- Add a small, additive hook to `MusicProvider`, e.g. `setTheaterTone(tone | null)`. When never called, the graph is byte-for-byte unchanged.
- Insert the tone filters AFTER the analyser: `source -> analyser -> lowpass -> lowshelf -> destination`. This way beat detection and the visual grading always read the true, undampened spectrum, and the dampen effect only changes what the player hears.
- Create the filters lazily on first `setTheaterTone` call and reconnect only then. On Jukebox exit, ramp back to transparent (20 kHz, 0 dB).
- Dampen to tone (starting values, tune by ear): lowpass Hz = 20000 * 0.5^(dampen * 1.2) (about 1.1 kHz at 3.5, 5.7 kHz at 1.5, 20 kHz at 0). Bass shelf dB = 4 * (1 - dampen / 3.5). Ramp with `setTargetAtTime(value, now, 0.6)`.
- Resume the context on every touch if suspended (the existing `visibilitychange` resume stays as is).

## 5. Tracks and gating
The 12 songs are `public/music/lokifed-take-1/00..11-*.m4a`, listed in `musicPlayer.tsx` (`unlockObjectiveCount` 0 to 11) and mirrored by `public/lok-soundtrack.json` (guarded by `lokSoundtrackCatalog.test.ts`). The Jukebox reads the existing `tracks` from `useMusicPlayer()`; it adds no files and no network calls.
- Default: respect in-game gating. Locked tracks show as sealed discs (like locked cards) and cannot play.
- Disc art is generated by the carousel (SVG patterns + palette, title printed on disc). One palette/pattern per track lives in the Jukebox manifest, not in the audio catalog.

## 6. Visuals and UI
- Full screen, near-black, `100svh`, safe-area padding, mobile-dynamic. Use CSS `dvh` for modal heights (see `fixed-popups-and-ancestor-filters.md`). Do not put filter/transform on the `[data-ui-theme]` wrapper.
- Carousel props: `frame={false}`, `details={false}`, `reviews={false}`, `controls={false}`, `brand=""`, `indexLabel=""`, `hint=""`, transparent or near-black `background`, `loop`, no `fontHref`.
- Audio-reactive grading: read bands from the existing `beatBus` / `useAudioFrame()` seam (never a new AnalyserNode in a consumer, per `music-reactivity.md`). Smooth bass/mid/treble with a slow lerp and write them to CSS variables (`--jb-bass`, `--jb-mid`, `--jb-treble`) that drive glow, hue shift, vignette and grain. Reduced motion: static grade.
- Slim UI bar: prev, play/pause, next, scrubber, title, close. Level 1 opacity 1, Level 2 about 0.35, Level 3 hidden with pointer-events off. 600 to 900 ms ease `cubic-bezier(0.16,1,0.3,1)`.
- Pause the frame loop and reactive grading when the tab is hidden.
