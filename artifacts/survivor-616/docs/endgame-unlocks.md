# Everything the end game unlocks

The same rows drive the table in Settings, End game (`ENDGAME_UNLOCK_TABLE` in `src/game/data/endgameUnlocks.ts`). A test checks every feature and slot is listed.

| Unlock | Type | How to earn it | Why |
| :--- | :--- | :--- | :--- |
| Victory Lap | Gate | Clear every standard map once (timed maps; not endless, not 2x/4x). | Proof you have seen the whole game; keeps the early game uncluttered. |
| Endgame weapon evolutions | Feature | Opens with Victory Lap; on by default, switch off any time. | Lets the DigiFrog Lance and Digi-Tana Trinity evolve. |
| Operator Forge | Feature | Opens with Victory Lap; off until you switch it on. | Workshop for your own operators, enemy looks and LokPet looks. |
| Zoom viewer | Feature | Opens with Victory Lap. | Full-size look at any operator. |
| Faction races | Feature | Opens with Victory Lap. | More species in the Forge. |
| Champion foil | Feature | Opens with Victory Lap. | Holographic sweep on your selected operator. |
| Glow aura | Feature | Opens with Victory Lap. | Tiles glow in each operator's color. |
| Slot: Full Circuit | Custom slot | Victory Lap. | First place to keep an operator you made. |
| Slot: Crowd Control | Custom slot | 20,000 total kills. | Slots are each earned their own way. |
| Slot: Roll Call | Custom slot | Rescue 15 allies. | |
| Slot: Field Notes | Custom slot | Find 18 discoveries. | |
| Slot: Beast Master | Custom slot | Win 25 LokPet battles. | |
| Ten GRPD endgame weapons | Weapons | Victory Lap, then 750,000 and 1,000,000 lifetime kills in turn; switch each on in the GRPD Armory. | Long-tail goals that do not touch new players. |
| Classic v1 look | Forge | With the Forge: pick Classic v1 on a design. | Original plain build for custom operators. |
| Custom enemy and LokPet looks | Forge | With the Forge: recolor and save. | Cosmetic only; each look has a run switch plus a master switch. |
| Custom Bestiary | Bestiary | Victory Lap. | See and switch your looks next to real threats. |
| Hideout Endgame dock | Hideout | Victory Lap; hide in Endgame settings. | Quick switches and shortcuts. |

Run switches: every custom operator and look has its own "use in runs" switch, plus a master "Use my customs in runs" switch with All on / All off. Operators need a reload to reach the roster; looks apply from the next run. Customs are not in card packs.
